# F21 — Today

## Strategy
Today is a chronological view of recent food stories from Kitchen Circles. It should help people find one appealing, cookable idea without requiring them to post. Ship in the social release after circle authorization and media delivery work. A proposed success measure is the proportion of opened stories leading to a recipe view, private save, or Make Mine; do not optimize dwell time or impose streaks.

## Experience and screen design
`HOME` links to `TODAY`, which shows circle filters, author, publication time, an accessible preview, and an explicit empty state. Order by `publishedAt DESC, id DESC`; unread status only changes an indicator, never ranking. `STORY` shows author, remaining availability, media controls, recipe attachment, reaction, private reply, and overflow actions. Advance is manual by default; reduced-motion preferences suppress transitions. `RECIPE`, `ADAPT`, `THREAD`, and `REPORT` are secondary destinations. Cooking remains available when Today is empty or disabled.

## Production sequence
Opening Today calls `GET /v1/posts/today?circleId=…&cursor=…`. The social service checks membership and blocks before returning each row. Opening a row calls `GET /v1/posts/{postId}?placement=today`; only then does the client request signed media delivery. A local account-scoped viewed marker powers the unread indicator without sending an author-facing read receipt. Optional minimized operational telemetry is independent of rendering. Publishing in F31 sets `publishedAt` and `expiresAt` in the same database transaction. An expiry worker removes derived feed entries; read-time checks remain authoritative if it is late.

## Data and API contracts
`Post(id,authorId,status,publishedAt,expiresAt,keepOnPlate,audienceVersion,version)` has server-assigned timestamps and `expiresAt = publishedAt + 24 hours`. Cursor contents include the last ordering tuple and query filter hash, with expiry and signature. Feed membership is computed from current authorization, not possession of an old cursor. Media URLs are issued separately. Return typed `POST_UNAVAILABLE`, `CURSOR_EXPIRED`, and `RATE_LIMITED`; a cursor refresh must not reveal deleted entries.

## Permissions and lifecycle
Today inclusion requires `PUBLISHED`, `serverNow < expiresAt`, and either authorship or an active authorized circle relationship without a block in either direction. Multiple matching circles produce one card. Circle removal, audience edits, blocks, and deletion take effect on the next authorized read and media request. At expiry an open Story stops playback and offers `POST` only if Keep on Plate independently permits access. Plate retention never extends Today visibility.

## Failure and offline behavior
Cache display metadata in encrypted, account-scoped storage with its expiry. Do not cache private source media for offline replay. If server-time uncertainty could cross expiry, hide the story until revalidated. Pagination deduplicates by post ID. Local viewed markers are discardable presentation state, not evidence that another device has seen a post. Offline cooking links may use an already authorized saved recipe copy.

## Integration and dependencies
Depends on F23, F24, F31, F40, and F42, identity, media, and server clock synchronization. F22 owns durable Plate placement; F30 owns copying. Feed workers consume `post.published`, `post.audience_changed`, `post.deleted`, `circle.member_removed`, and `block.created` without becoming the access authority.

## Execution plan
Implement the authorization query and cursor contract first, then Compose list/story states, media cancellation, and expiry invalidation. Add an expiry worker and local viewed markers last. Measure authorization denials, stale-card removals, and feed latency without recording private captions.

## Acceptance and release gates
Test the exact expiry boundary, delayed workers, overlapping circles, removed members, reciprocal blocks, expired cursors, and an already-open story. Proposed target: all authorization fixtures pass and no new media capability is issued after revocation. Existing signed URLs retain the residual lifetime documented in F38, bounded by Today expiry when issued for that surface. `social.today.enabled` hides discovery while preserving personal cooking and Plate management; disabling telemetry must not affect viewing.
